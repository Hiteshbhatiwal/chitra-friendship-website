# Media Directory Guide 💌

This directory is prepared for your personal media files for **"A Little World of Chitra"**.

## Directory Structure:
- `photos/`: Place your approximately 8 school photos here.
  - Recommended filenames: `photo-1.jpg`, `photo-2.jpg`, ..., `photo-8.jpg` (or `.png`, `.webp`).
- `videos/`: Optional school videos or reels (`.mp4`, `.webm`).
  - Leave empty if no videos are ready; the website will display an optional graceful placeholder.
- `audio/`: Optional background music track.
  - Recommended filename: `background-melody.mp3`.
  - Music is strictly OFF by default and will only play if Chitra clicks the audio button.
- `stickers/`: Optional custom stickers or graphics.

## Graceful Fallback:
Until you copy your actual files here, the application automatically displays cute, pastel SVG scrapbook placeholders so you can preview and test the complete design without any broken links or missing image icons!
